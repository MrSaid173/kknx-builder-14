# swappiness до 200

В 4.9 потолок `vm.swappiness` равен 100. Формула в `get_scan_count()` в этом дереве уже содержит `anon_prio = swappiness; file_prio = 200 - anon_prio`, а в defconfig включён `CONFIG_BALANCE_ANON_FILE_RECLAIM=y` (файловый кэш не получает преимущества автоматически), поэтому значение выше 100 здесь действительно смещает reclaim в сторону anon (в zram). Патч только поднимает предел sysctl до 200 (в Linux 5.8 это сделано вместе с переработкой баланса LRU; она в 4.9 не нужна).

Включение: `experiments=swapmax` (предел) или `swap150` (предел + группа `vm` пишет 150). На 200 доля файлового кэша в reclaim нулевая, берите 120-160 и сравнивайте через `kknx-test.sh mem` / `memlog`.

Файл: `kernel/sysctl.c`. Проверено: накладывается, компилируется. Не проверено: на устройстве.
